# Coastal El Niño in CMIP6 models: frequency, mechanisms, and links to mean-state and ENSO biases

This repository contains code and data for the analysis presented in the study "Coastal El Niño in CMIP6 models: frequency, mechanisms, and links to mean-state and ENSO biases".
The study investigates the representation of Coastal El Niño events in CMIP6 climate models, examining their frequency, underlying mechanisms, and connections to mean-state biases and ENSO dynamics.

## Data:
Additional data needed for the composites can be downloaded from the following sources:
- ERSSTv5 sea surface temperature data: [NOAA ERSST](https://climatedataguide.ucar.edu/climate-data/sst-data-noaa-extended-reconstruction-ssts-version-5-ersstv5)
- HadISST sea ice concentration data: [HadISST](https://www.metoffice.gov.uk/hadobs/hadisst/)
- ERA5 wind stress and precipitation data: [ECMWF ERA5](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels-monthly-means?tab=download)
- 20CRv3 precipitation data: [20CRv3](https://psl.noaa.gov/data/gridded/data.20thC_ReanV3.html)

Model data and output from the CLIVAR ENSO 2020 package can be accessed from the Zenodo record:

- Rivera Tello, G., & Karamperidou, C. (2025). Dataset for manuscript: "Coastal El Niño in CMIP6 models: frequency, mechanisms, and links to mean-state and ENSO biases" [Data set]. Zenodo. https://doi.org/10.5281/zenodo.17750456
