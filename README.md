# Coastal El Niño in CMIP6 models: frequency, mechanisms, and links to mean-state and ENSO biases

This repository contains code and data for the analysis presented in the study "Coastal El Niño in CMIP6 models: frequency, mechanisms, and links to mean-state and ENSO biases". The study investigates the representation of Coastal El Niño events in CMIP6 climate models, examining their frequency, underlying mechanisms, and connections to mean-state biases and ENSO dynamics.
