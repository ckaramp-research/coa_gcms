# Data Directory
This directory contains the lightweight data used for the metrics and the barplot in the manuscript (`plot_barplot.ipynb` and `plot_metrics.ipynb`).
Heavier dataset files can be downloaded from zenodo to reproduce the composite plots in the notebook `plot_composite.ipynb`.

CMIP6 data has been accessed from the ESGF data portal (https://esgf-node.llnl.gov/projects/cmip6/) and regridded to a common 1°x1° grid using xESMF. Coastal El Niño statistics and metrics were derived from the regridded data.
